Which terms make up this number?
How to read
Each term looks like
(d x 10^n)
where d is the digit and n is its place.

Example:
(4 x 10^3) = 4,000
(7 x 10^2) = 700
(5 x 10^0) = 5

Sum = 4,705

Notice: no (x 10^1) term -- the tens digit is 0, so it vanishes.
Insight
Zero digits disappear from expanded form. That is why expanded form can be shorter than the number of digits.
